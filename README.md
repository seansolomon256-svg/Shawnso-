          # Shawnso Electrical & Solar. Consultants Website

         Static website package for Shawnso Electrical & Solar Consultants.

         ## IMPORTANT: Email setup

         The site is prepared to send Contact, Quote, Site Visit and Product Enquiry submissions through Formspree.

          Because a Formspree form ID is unique to your account, it cannot be safely invented in this package.

          ### One-time setup

          1. Create/verify the business email `seansolomon256@gmail.com` in your Formspree account.
           2. Create a new Form.
           3. Copy its endpoint, for example `https://formspree.io/f/xxxxxxxx`.
           4. Open `assets/js/config.js`.
           5. Replace:
   `https://formspree.io/f/REPLACE_WITH_YOUR_FORM_ID`
          with your real Formspree endpoint.
          6. Upload the complete folder to.   GitHub Pages.

          After this, all four website forms use the same endpoint and submissions can be delivered to the configured target email.

          ## GitHub Pages

          Upload the contents of this folder to a GitHub repository. Keep `index.html` in the repository root. Enable GitHub Pages from Settings > Pages and deploy from the main branch/root.
